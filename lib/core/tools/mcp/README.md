# 🎨 Figma Integration Tool

هذه الأداة مصممة لتسهيل ربط مشاريعك في Figma بكود Flutter الخاص بك عبر الذكاء الاصطناعي.

## 🚀 كيفية الاستخدام (للمرة الأولى)
قم بتشغيل الأمر التالي مع التوكن الخاص بك:
```bash
python lib/core/tools/mcp/figma_mcp_config_fixed.py figd_YOUR_TOKEN_HERE
```
**ماذا سيفعل هذا السكريبت؟**
1. سيقوم بتثبيت المكتبات اللازمة تلقائياً (`httpx`, `mcp`).
2. سيقوم بحفظ التوكن في مكان آمن على جهازك ليتمكن الـ AI من قراءته لاحقاً.

## 🤖 لطلب المساعدة من الـ AI
بعد الإعداد، يمكنك ببساطة إعطاء الـ AI رابط ملف الفيجما وطلب تنفيذ أي مهمة (استخراج ألوان، بناء Widgets، إلخ).
لمزيد من التفاصيل التقنية للـ AI، راجع ملف `AI_PROMPT_GUIDE.md`.
